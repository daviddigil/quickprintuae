# QuickPrint UAE brand (from the owner's brand sheet)

Wordmark: **QUICKPRINT** (heavy geometric sans, navy) over **UAE.COM** (teal). Logo: glossy glass-gradient "QP" monogram (teal → magenta → royal blue loops, soft shadow) on white.
The master logo file was only shared as an image in chat: drop the original (SVG/PNG, transparent) at `web/public/brand/logo.svg` and use it in the header, favicon and OG image. Until then use a text wordmark.

| Token | Hex | RGB | CMYK |
|---|---|---|---|
| Magenta (accent / CTA highlight) | #FF007F | 255 0 127 | 0 100 50 0 |
| Teal/Cyan (success, highlights) | #00FFCC | 0 255 204 | 100 0 20 0 |
| Royal Blue (primary actions, links) | #3300FF | 51 0 255 | 80 100 0 0 |
| Navy (text, dark surfaces) | #1D1E3A | | |
| White | #FFFFFF | | |

Signature gradient: teal → magenta → royal blue (use sparingly: logo, hero accents, thin divider lines under letterheads).
Style: rounded corners (~16px), generous whitespace, glass/gradient accents, navy dark mode (dashboard mock-ups use navy surfaces with gradient cards).
Accessibility: #00FFCC and #FF007F on white fail contrast for body text. Use navy text; use teal/magenta only for fills, borders, large display text or on navy backgrounds.
Typography: bold geometric/SF-style sans (Inter or system SF stack), tight tracking on headings, uppercase wordmark.
